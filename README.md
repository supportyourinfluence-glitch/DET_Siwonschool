# DET 실전 VOCA 체험판

- `docs/`: 배포되는 앱. GitHub Pages가 `main` 브랜치의 `/docs` 폴더를 그대로 보여 줍니다.
- 앱을 고친 뒤 다시 만들기: `python 02샘플앱/tools/build_trial.py --out 05배포_체험판/docs` 실행 후 커밋하고 올린다.

단어와 뜻의 권리는 해당 교재 출판사에 있습니다. 이미지 출처는 앱의 `credits.html`에 있습니다.
